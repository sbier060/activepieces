# TextKit

[TextKit](https://jointextkit.com) is an SMS API. This piece sends texts, runs phone verification, and triggers a flow when one of your numbers receives a text.

Create an API key in the [TextKit console](https://jointextkit.com/console) under **API Keys**. A test key (`ssms_sk_test_...`) runs in the sandbox: sending to `+15005550006` always ends `delivered`, and the verification code is `111111`.
